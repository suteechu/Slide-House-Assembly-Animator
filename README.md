# Integrated Design & BOM Automation (V4)

Standalone Ver4 presentation studio (React + Vite + Tailwind CSS + Framer Motion + Native 1920x1080 Canvas Engine) featuring all **16 slides (`01`–`16`)**, live animated simulator clips, SCG HEIM Interior/BOM icons, and normal `1.0x` time-synced Thai narration (`14:57` / `897s`).

## Quick Start

1. Double-click `Start_Ver4.bat` (or run from terminal):
   ```bash
   npm install
   npm run build
   npm start
   ```
2. Open Chrome at `http://127.0.0.1:8787`
